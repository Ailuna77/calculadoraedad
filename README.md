## 📝 Descripción del Proyecto
### Presentación de la Actividad
Este proyecto consiste en un repaso de los conceptos de lógica y algoritmos trabajados el año pasado. En esta oportunidad, se desarrollará en **Python** para compararlo con el lenguaje estructurado de bajo nivel en **C++**.

**El objetivo:** Escribir un programa que calcule la edad exacta de una persona restando su año de nacimiento con el año actual. El programa debe verificar de forma estricta que las fechas ingresadas existan en el calendario real (contemplando años bisiestos y la cantidad exacta de días de cada mes).

## 🛠️ Requisitos e Instalación

1. Asegúrate de tener instalado **Python 3.12+** y **Git**.
2. Clona el repositorio en tu máquina local:
   ```bash
   git clone https://github.com/GabZac/Actividad-1-Revision-Integral.git
   ```
3. Instala **Flask** desde la terminal de tu editor de código (ej. VSCode):
   ```bash
   pip install flask
   ```

---

## 🚀 Ejecución

Para encender el servidor de desarrollo, sitúate en la carpeta raíz del proyecto y ejecuta el siguiente comando en la terminal:

```bash
python backend/app.py
```
